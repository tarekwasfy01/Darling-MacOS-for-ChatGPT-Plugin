# Darling Runtime — skills-only plugin

Bundled Darling binaries for Ubuntu 24.04 amd64, optimized for macOS CLI/compiler workflows while keeping the plugin below 100 MB.

See `skills/darling-runtime/SKILL.md`, `licenses/`, and `MANIFEST.sha256`.

For OpenAI public-directory submission, publisher identity and the required public website/support/privacy/terms URLs must still be supplied and verified in `plugin.json`/the submission flow.

# Add Marketplace & Plugin

Open ChatGPT → Settings → Plugins.

Add this repository as an external marketplace/source:
https://github.com/tarekwasfy01/Darling-MacOS-for-ChatGPT-Plugin

Open the newly added marketplace and select Darling Runtime.

Click Install or Add to ChatGPT.

Start a new chat and select Darling Runtime from your installed plugins.

After installation, you can ask ChatGPT to set up Darling, inspect Mach-O binaries, or help run compatible macOS CLI tools on Linux.
