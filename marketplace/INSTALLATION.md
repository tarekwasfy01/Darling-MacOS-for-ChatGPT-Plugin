# Installation & Compatibility

## Target environment

- Ubuntu 24.04 LTS
- amd64 / x86_64
- Linux host with permission to install the required system packages

The main plugin package contains the bundled Darling packages and its own installation guidance.

## Intended use

The package focuses on compatible macOS command-line applications, Mach-O binaries, compilers, and developer workflows.

## Limitations

Compatibility is application-specific. GUI applications and software relying on unsupported Apple frameworks or operating-system behavior may not work. A skills-only package also does not automatically grant a host environment permission to execute local processes.
