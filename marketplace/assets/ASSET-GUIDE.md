# Marketplace Asset Guide

`icon.png` is the primary marketplace icon.

For marketplaces that require additional media, create derivatives from the same visual identity rather than introducing third-party logos.

Suggested optional assets:
- Square icon: 1024 × 1024
- Listing card: 1200 × 630
- Wide banner: 1600 × 900
- 2–4 screenshots showing CLI/compiler-oriented usage

Keep screenshots free of credentials, personal files, API keys, copyrighted third-party application artwork, and unnecessary third-party branding.
