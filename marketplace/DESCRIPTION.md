# Darling Runtime

**Run compatible macOS command-line tools on Linux.**

Darling Runtime is a compact, skills-only package built around the open-source Darling compatibility layer. It is intended primarily for developers who need to inspect, configure, or run compatible Mach-O command-line applications, compilers, and related developer tooling on a supported Linux host.

## Highlights

- Focused on macOS command-line compatibility
- Intended for compilers and developer workflows
- Bundled selected Darling runtime components
- Ubuntu 24.04 amd64 target environment
- No full macOS virtual machine required
- Installation and integrity information included
- Open-source notices and licensing information included

Compatibility depends on the individual application and host environment. Not every macOS application, framework, GUI application, or system feature is supported.
