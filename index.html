macOS CLI compatibility on Linux

Darling Skill

A compact skill package containing selected Darling components for running compatible macOS command-line tools, compilers and development software on Linux.

Learn more

What it provides

CLI focused

Designed around command-line tools, compilers and developer workflows.

Compact

A curated Darling distribution designed around a small package footprint.

Open source

Darling components are distributed under their applicable open-source licenses, including GPL-3.0 components.

Self-contained

Includes selected runtime binaries, licensing information and supporting documentation.

About Darling

Darling is an open-source compatibility layer that implements macOS APIs and system facilities on Linux. Compatibility varies by application; this package does not claim that every macOS program will run.
